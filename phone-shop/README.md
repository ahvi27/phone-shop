# Pulse — TypeScript Phone Shop

## View immediately
Open `dist/index.html` in your browser. No installation needed. All illustrations are included and the site works offline.

## Develop
Install Node.js, then run:
```sh
npm install
npm run typecheck
npm run build
npm run dev
```
Open http://localhost:5173. Edit `src/app.ts` and `dist/styles.css` / `dist/index.html`, then rebuild.

## Features
Responsive catalog, brand and budget filters, search, price sorting, product details, storage and color options, comparison of up to three phones, quantity controls, saved cart, and validated demo checkout. Cart storage uses this browser; browser settings may restrict saving when opened as a local file.

All brands, specifications and USD prices are fictional examples. This is a front-end portfolio demo. No payment processing, inventory service, taxes, real orders or deliveries are implemented. Checkout contact details are neither saved nor sent. Replace demo data and connect a secure backend before operating a real store. Original SVG phone illustrations are included.
